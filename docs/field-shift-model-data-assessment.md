# Field Shift 数据与 MILP 求解适用性评估

> 评估对象：[`field-shift-challenge-page.md`](field-shift-challenge-page.md) 所列资源；模型依据：[`NASA-modeling.md`](NASA-modeling.md) 的轮作策略优化 MILP 数学规格。本文评估如何获取、如何预处理、可以支撑哪些模型参数，以及数据是否足以形成可求解实例。页面外的农艺和经营输入只作为缺口列出，不扩展其外部来源评估。未指定具体农场/田块坐标，因此获取步骤为通用流程；本文未实际下载或验证任何外部数据。

## 1. 结论

挑战页给出的是候选数据目录，不是可直接提交给 Gurobi 的输入包。页面资源中最适合构建环境特征的是 NASA POWER（气象）、GPM IMERG（降水）、SMAP（区域土壤水分）、一个 DEM（地形）、Landsat/MODIS/VIIRS（植被与地表状态）和按需使用的 ECOSTRESS（热状态/ET）。这些数据都必须先做检索区裁剪、QA、单位统一、尺度匹配、时间聚合和参数估算。

即使上述数据全部获取，仍不能独立求解 `NASA-modeling.md` 中的完整 MILP。模型还需要页面资源未给出的田块边界和面积、作物参数与播种窗口、土壤水力参数、农户偏好、种植成本与价格、作物产量、设备能力、种子供应、市场消纳能力、灌溉水源能力和可接受风险阈值。少了这些，不只是精度下降，而是目标函数、候选集或约束参数无法完整定义。

**条件判断：**

- **可计算环境参数：有条件可以。** 若提供研究区、日期、产品版本及有效像元，POWER/GPM/SMAP/DEM/植被数据可以支持部分温度、降水、区域水分、地形和植被代理特征。
- **可建立完整模型输入：不能仅靠挑战页资源。** NASA 及其他遥感/公共数据不提供完整田块经营、作物生理和供需约束数据。
- **可求得数值解：需要额外业务输入后才有可能。** 求解器要求预处理完成后的确定性参数；数据目录本身不会生成候选作物方案，也不会自动证明方案农艺可行或可实施。
- **可作为农场实施建议：遥感数据本身不够。** 模型结果仍需农户、当地农艺专家及供水/供应/销售方确认，尤其当模型缺口变量大于零时。

## 2. 资源逐项评估

表中“可入模”专指可否为 `NASA-modeling.md` 的预计算参数提供直接数值，**不表示数据可不经处理直接作为 MILP 变量或约束**。NASA Earthdata/LP DAAC/GES DISC 下载通常需要 Earthdata Login；具体产品版本、访问权限、延迟和变量名应以下载时的产品文档及元数据为准。

### 2.1 NASA 数据与资源

| 页面资源 / 来源 | 如何获取及典型数据 | 尺度、QA 与主要处理 | 对应模型参数；可入模性 |
|---|---|---|---|
| **SMAP**（NASA） | 在 [Earthdata Search](https://search.earthdata.nasa.gov/) 搜索 SMAP；区域根区水分可优先评估 `SPL4SMGP` L4，表层观测可用 `SPL3SMP_E` L3作对照。下载 HDF5/NetCDF 等产品文件和元数据。 | L4 常见网格约 9 km、3 小时；L3 约 9 km、日尺度。读取表层/根区含水量变量、单位、质量标志和缺测值；按包含田块的原生网格或邻域汇总，不能重采样成田内测量。 | 可用于区域水分异常、干旱/水分风险代理、播种前水分状态的粗尺度参考，以及 `D_{fk,s(k)-1}` 的区域先验/校验。不能直接给出田块 `theta_FC`、`theta_WP`、`TAW/RAW`，也不能单独算 `q_{fkt}`；空间尺度通常不足以代表单块田。**辅助入模，不是田块土壤水真值。** |
| **GPM / IMERG**（NASA） | 在 Earthdata Search 或 [GPM 数据入口](https://gpm.nasa.gov/data) 检索 IMERG；历史训练优先用 IMERG Final，逐日产品用于水量平衡，半小时产品用于暴雨。Early/Late 只适合近实时，不能和 Final 未标记混训。 | 典型 0.1°（约 10 km）；半小时、日、月产品。质量指数、液态降水概率、随机误差、产品运行阶段均应保留。若读取降水率，须按时间间隔换算为累计水深；检查单位是 mm/h、mm/半小时还是累计 mm。 | 可构造 `P_{ft}` 的区域背景和 `P^{eff}_{ft}` 的输入，再经当地有效降雨系数估算；可构造极端降水/干旱风险、季节降水统计。不能给出田块有效降雨比例 `eta^P`、径流/入渗或作物阈值。粗网格不能冒充田间雨量计。**对水量平衡和风险重要，但需本地校准。** |
| **Landsat、MODIS、VIIRS：反射率/NDVI/植被指数**（NASA/USGS 产品） | 页面给出的 [EarthExplorer](https://earthexplorer.usgs.gov/)、[LP DAAC MODIS 产品目录](https://lpdaac.usgs.gov/products/) 和 [Earthdata VIIRS 搜索](https://search.earthdata.nasa.gov/search?q=VIIRS)。选择地表反射率/植被指数的明确产品和版本；下载影像、质量层和元数据。 | Landsat 地表反射率典型 30 m、重访约 16 天（多星可增加观测）；MODIS 植被产品常见 250 m/16 天，VIIRS 产品尺度和合成期依产品而异。云、云影、雪、水体和质量分类必须掩膜；不能把无效值插值为有效观测。按田块多边形算 NDVI/EVI、裸地比例、物候和有效像元率。 | 可支持 `b_{fkt}`（覆盖状态）的遥感证据、作物生长/胁迫背景及 `h^{OM}`/侵蚀等指标的弱代理；时间序列可辅助候选方案验证。NDVI 不是土壤有机质或氮素测量，植被覆盖不一定等于有效地表保护，单景不能判定轮作效应。**覆盖/胁迫辅助特征；不能直接产生土壤健康贡献评分。** |
| **NASA POWER**（NASA） | [POWER API](https://power.larc.nasa.gov/) 可按经纬度、时间范围和变量取日/月/小时点位序列；也可用其 API 文档构造批量请求。优先保留原始 JSON/CSV、请求参数和响应元数据。 | 全球格点/网格驱动的气象与辐射资料，网格远粗于田块。按模型要求取 `T2M`, `T2M_MAX`, `T2M_MIN`, `T2MDEW`/湿度、`WS2M`, `PS`, 短波辐射和降水等可用变量；核对变量是否支持请求的时间分辨率，单位与缺测标记。 | 是积温 `GDD_{c,d}`、热/冷/霜冻风险、FAO-56 `ET0_{ft}` 的主要气象输入；可派生热浪、霜冻持续期等。ET0 要有完整或明确近似的辐射、风、湿度/水汽压、气温输入；POWER 不提供作物 `T_base/T_upper/G_c/K_c`，也不是田间站点。**NASA 数据中最核心的气象输入，但必须与作物参数结合。** |
| **GRACE / GRACE-FO**（NASA；在挑战详情的示例数据中列出） | 通过 [NASA PO.DAAC](https://podaac.jpl.nasa.gov/) 或 Earthdata Search 检索 JPL GRACE/GRACE-FO 月产品；优先查找已处理的 JPL Mascon CRI 等效水厚异常产品。下载时核对任务、版本、变量、参考基线和缺月；不能把任意 Level-2 文件都当作总水储量产品。 | 月尺度、粗空间支持尺度；Mascon 发布网格可能比独立有效分辨率更细，独立有效尺度约为数百公里量级。GRACE 任务交接期有缺口。保留质量/泄漏处理说明、单位、基准期及不确定度。 | 可作为流域/月尺度总水储量异常与长期干旱背景，支持 `r^{drought}_{fk}` 的慢变量背景或长期水趋势说明；不能下采样成田块独立信息，也不能解释成地下水单项、可抽取水量或日供水 `W^{max}_{rt}`。Level-2 球谐系数须经改正、滤波和反演；**优先处理后的 Mascon，长期背景辅助项，不是日灌溉输入。** |
| **SRTM**（NASA） | 通过 [Earthdata SRTM 页面](https://earthdata.nasa.gov/data/instruments/srtm) 或 Earthdata Search 获取研究区瓦片；用 GIS/DEM 工具拼接并裁剪。 | 常见 1 弧秒约 30 m；覆盖约 60°N–56°S。先做投影/垂直基准检查、空洞/异常值检查，再派生坡度、坡向、汇流/地形湿度等；派生水文变量需明确 DEM 水文填洼处理。 | 可支持 `sigma^{terrain}_{fk}` 的坡度/地形初筛、侵蚀和汇流背景风险。不能给出机械通行、排水设施和实际积水情况；高程也不提供田块土壤或灌溉能力。**静态地形协变量；与 NASADEM 二选一即可。** |
| **ECOSTRESS**（NASA） | 在 Earthdata Search/LP DAAC 检索 `ECO_L2T_LSTE`（LST）和 `ECO_L3T_JET`（ET），按田块附近过境时间下载；保留云、水体、误差和 QA 波段。 | 约 70 m；ISS 轨道导致过境时间和间隔不规则，受云影响。按田块多边形计算有效像元比例、中位数/分位数和不确定度；不得把不规则过境线性插值成连续“实测日序列”。 | LST 可支持热暴露/植被胁迫的田块级补充证据；JET 可对 `ETc`/水分平衡估计作观测校验或局地 ET 特征。它不等于 2 m 空气温度，也不自动给出 FAO-56 `ET0`、作物系数或灌溉需求。**高价值但稀疏的校验/增强层，不是连续主数据。** |

### 2.3 空间机构合作伙伴资源

### 3.1 可以直接从数据计算与只能作代理的边界

**较接近直接数值输入（仍需产品处理）：** POWER/ERA5 日气象序列、IMERG 总降水、SMAP 格点水分、DEM 高程及派生坡度、Landsat/Sentinel/MODIS 质量筛选后的反射率/指数、ECOSTRESS 观测 LST/ET、NASS 区域历史产量、AMS 报价记录。它们是源观测或产品变量，不等于模型的田块决策参数。

**只能作为代理/背景证据：** 卫星 NDVI→作物胁迫或覆盖；SMAP→田块根区水分；GAEZ→本地品种适宜性/产量；GEDI→耕地生物量；NLCD→具体轮作/作物类型；NWIS→农场可用灌溉水；AMS 报价→实际市场消纳能力。使用时须把 proxy、空间/时间尺度、误差和置信度显式存入特征，而不能标成地面真值。

## 4. 建议获取顺序与最小数据组合

### P0：可计算环境与水量平衡候选参数

1. **先确定 AOI、田块多边形、计划期和坐标系。** 没有田块几何就无法裁剪、面积加权或计算 `A_f`；本报告因未提供 AOI，不能给出具体 granule、覆盖率或 API 请求参数。
2. **NASA POWER 日/小时气象**：获取积温和 FAO-56 ET0 所需变量；保存请求参数、原始响应、单位和时间戳。
3. **IMERG Final Daily + Half-hourly**：Daily 用于日水量平衡，半小时用于极端降水；保存 QA、误差和产品阶段。
4. **SMAP SPL4SMGP**：作为区域根区水分/干旱背景；以 SPL3SMP_E 或地面记录进行一致性检查，不把两者作为相互独立田块测量。
5. **单一 DEM（SRTM 或 NASADEM）**：派生坡度、汇流等；不要重复叠加同源 DEM。
6. **Landsat 或 Sentinel-2 时间序列**：作为田块覆盖/物候/胁迫证据；MODIS/VIIRS 用于长基线或云缺测背景，不重复计权。
7. **GRACE/GRACE-FO Mascon（可选慢变量）**：仅在需要流域/区域长期水储量趋势时获取，不能替代日尺度田块水分或供水能力。

### P1：校验和田块级增强

- ECOSTRESS `ECO_L2T_LSTE`/`ECO_L3T_JET`：仅在 AOI 有足够无云有效像元时用于田块热状态和 ET 校验。
- GAEZ：作全球尺度的候选作物适宜性/情景筛选，不作本地确定性决策。
- 研究区若在美国：用 WSS/SSURGO 补土壤，CDL/NASS 补作物历史与产量背景；CoCoRaHS/PRISM 校验降雨和气候，NWIS 提供水文背景。
- OpenET 仅适用于其覆盖区；ERA5/NLDAS/GLDAS 作为气象/水文替代或交叉检查源，需先处理重叠，不能简单全部拼入模型。

### P2：视研究问题选取

USDA Ag Data Commons 的具体研究数据、NAIP、NLCD、AMS Market News、GEDI、LANDFIRE，以及额外的 MODIS/VIIRS 变量，只在有明确候选参数、研究区覆盖或校验目标时纳入。避免为了“用上所有资源”造成重复特征、尺度伪精度或无法解释的指标。

### 仓库已有样本的适用性

`data/sample` 当前已有 ECOSTRESS LST/JET、GPM Early/Late/Final（半小时、日、月）、GRACE/GRACE-FO、HLS L30/S30、MODIS MCD43A4/MOD11A2/MOD13Q1、SMAP L3/L4 和 SRTM 的原始样本文件。仓库样本说明将原始文件放在 `raw/`，说明这些是演示/处理样本，不代表覆盖完整。

当前盘点显示这些文件是少量单 granule/单景，而非覆盖同一农场的连续历史序列；尚不能据此计算稳定气候态、物候、逐日灌溉需水或像元有效率的长期分布。挑战页其他资源（如 POWER、土壤图、市场/供水等）也不因样本目录存在而视为已具备。具体空间覆盖、变量完整性和处理结果仍需在 AOI 确定后检查。

尤其是现有 GRACE-FO 文件名为 `GAA-2_...`。依仓库已有数据源评估，它是大气去混叠场，不是 GSM 或等效水厚/总水储量异常，不能拿来填补长期水趋势参数；应另行获取正确处理的 JPL Mascon 产品。**这只是现有样本的元数据/类型警示，不代表本文下载或重处理过该文件。**

## 5. 求解就绪检查与关键缺口

在把数据交给 NASA-modeling 的 MILP 预处理流程前，至少要建立如下完整映射；其中标为“页面未提供”的项目是求解阻断项，不应由遥感代理静默补造。

| 必需输入 | 页面资源覆盖情况 | 对求解的影响 |
|---|---|---|
| 田块集合/边界/面积 `F, A_f`，计划期、作物集合 `C` | 没有 | 无空间汇总单元和面积换算，不能构造变量/目标/供水量。 |
| 作物科属、`T_base/T_upper/G_c`、最大生育期、播种窗口、换茬时间、`K_c`、阶段比例、根深和 `p` | 没有；GAEZ/CDL 只能提供背景或历史标签 | 无法生成成熟日期、候选种植方案及可信作物需水。 |
| 田块 `theta_FC/theta_WP`、有效土层深度、播种前水分 | 部分土壤图/SMAP 可提供粗估或先验；页面数据不能保证田块实测 | 无法严谨计算 `TAW`, `RAW`, 初始缺水和 `q_{fkt}`。 |
| 产量 `Y`、价格 `v`、成本 `C` | 美国 NASS/AMS 有区域历史/报价；其他地区不一定覆盖，且不是农户级 | 无法准确计算净收益；历史统计不能直接代表新轮作情景收益。 |
| 轮作组合收益 `rho`、同科间隔 `L_g`、土壤健康评分映射与权重 | 没有明确数值 | 对应目标和冲突约束无法参数化；遥感数据不包含农艺因果规则。 |
| 水源/灌溉系统映射、净供水能力 `Wmax`、灌溉效率 | 页面只有间接水文背景 | 水量约束及 `u_water` 无法形成事实约束。 |
| 设备工时 `m/Hmax`、种子用量/供应 `b_seed/Smax`、市场消纳 `Dmax` | 没有；AMS 仅价格/市场报告，NASS 仅统计背景 | 设备、供应、市场约束和对应软缺口目标缺参数。 |
| `b_fkt`, `Bmax_f`、风险阈值与权重、目标归一化尺度和权重 | 遥感只能辅助估覆盖/风险；阈值/偏好未给出 | 覆盖、风险、健康等多目标不能形成可解释且可审核的评分。 |

**因此：** 最小遥感组合可以支撑“生成环境特征和风险证据”的子流程；要使完整 MILP 有定义且具有农艺/经营意义，必须补齐上表缺失输入，并保证每个田块过滤后仍有农户确认的基准候选方案。若仅以挑战页资源形成一个数值 MILP，必须把未观测量作为明确假设或情景参数，而不能声称由 NASA 数据客观推导。

## 6. 数据质量、尺度与可复现要求

每个下载产品都应保存产品短名/版本、原始 URL 或 API 请求、查询 AOI/时间、下载日期、变量、单位、QA 规则、granule ID 和处理代码版本。进入特征表前检查：

- 时间：统一时区/日界线；降雨率正确换累计量；观测日期和产品合成窗口分开存储。
- 空间：保留原生尺度；田块数据按边界做面积统计；区域/流域数据连接时标明有效尺度，禁止将 9–10 km 栅格插值后伪称 30 m 田块观测。
- QA：云、云影、雪、水体、缺测、质量等级、随机误差和产品阶段必须可追溯；分类/QA 层不可做双线性插值。
- 物理量：空气温度与 LST 分开；总降水与有效降雨分开；ET0、实际 ET、作物 ET 和灌溉量分开；总水储量/水分背景不等于地下水可开采量。
- 时间覆盖：生成逐日/逐月 granule 数量、缺测率、云量和有效像元矩阵；不得使用不同产品的内连接把训练期缩到少云或特定季节。
- 地域：WSS、SSURGO、CDL、PRISM、NAIP、NLCD、CoCoRaHS、NWIS、NASS、AMS、OpenET、LANDFIRE 等有明确美国/区域限制。全球挑战不能默认这些数据可用；本地替代源需要另行明确后才可落地。

## 7. 最终判断

挑战页资源适合作为**模型环境特征、风险筛选、校验和解释性证据**，并可支持若干 MILP 预计算量；它们不是完整农业经营数据库。模型就绪程度可分为：

1. **环境特征可准备：有条件可行**，前提是 AOI/日期明确、产品覆盖充分、QA 和尺度处理正确。
2. **九项目标特征完整：不可仅凭页面资源保证**，温度/降水/土壤水分/植被等可以构造部分指标，但蒸散、霜冻、土壤健康和长期水风险都需要作物/土壤/农艺定义。
3. **完整 MILP 参数化并求解：当前不可由挑战页资源单独实现**，因为目标收益、候选方案、经营资源约束和多目标权重等关键信息不在这些资源中。
4. **可实施轮作建议：必须人工确认**，尤其是正的水、设备、种子、市场或裸地缺口，以及代理指标覆盖不足的田块。

推荐结论表述为：**“这些资源可为轮作 MILP 提供环境侧输入与佐证，但不能单独使完整运筹模型可解；只有在补齐田块、作物、土壤水力、经济和经营约束数据，并对代理参数做本地验证后，才可求解并将结果作为决策支持。”**
