# Sideronostos：一套主题，局部表面

页面始终使用黑灰画布 `#090a0a`，荧光绿 `#bdff72` 只突出主操作与关键状态。没有全站明暗切换。`tone` 表示组件所在的局部配色，不是全站主题。

## 表面接口

```tsx
<Surface>常规深灰面板</Surface>
<Card surface="light">米白重点内容</Card>
<Surface material="glass">图片上的烟灰操作区</Surface>
<Card material="glass">地图上的指标面板</Card>
```

- `Surface tone="dark" | "light"`、`Card surface="dark" | "light"`：未指定时继承局部配色，根级默认深灰。
- `material="solid" | "glass"`：每个容器默认实心；不会隐式给子卡片添加模糊。
- 玻璃固定使用烟灰配色，即使外层是米白、或同时传入 `tone="light"`。背景图片明暗不改变配色。
- 实心深灰 `#242626` 用于日常操作，米白 `#e9ebe5` 用于重点内容。玻璃底色为深灰 68% 不透明度、14px 背景模糊、细边框、内高光和柔和阴影。
- 玻璃浮层增加到 92% 遮蔽度。显式嵌套玻璃只保留外层模糊；表单、徽标、按钮不单独模糊。不支持背景模糊时回退到实心深灰。
- `useSurface()` 继续返回局部 tone；新增 `useSurfaceAppearance()` 返回 `{ tone, material }`。Portal 在 DOM 外显式恢复两项属性。不要以 DOM 祖先选择器替代 React 上下文。
- 旧 `.glass-*`、`.brand-gradient-*` 仍为实心语义样式兼容入口，不用它们启用新材质。

## 组合模式

`components/ui/patterns.tsx` 提供：

- `ActionTile`：44px 图标区、标题/描述、方向提示组成横向流程入口，沿用 Landing 的节奏。
- `MetricPanel`：大数字、低强调标签、共用分隔线组成指标面板，支持所有局部表面。
- `FloatingToolbar`：一层材质包裹整组搜索/操作/导航，默认玻璃，可显式传入实心材质。
- `Button` 保留原尺寸，增加 `size="action"`（48px）与 `size="hero"`（60px）。次级操作和辅助徽标使用中性灰阶。

`/components` 的三种预览共用示例数据，但每个实例独立维护筛选、分页、弹窗、日期详情和甘特图快照。米白始终处于黑灰页面内；玻璃预览复用参考页的本地照片素材。
